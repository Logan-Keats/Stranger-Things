**BORROW. SHARE. REUSE.**

Stranger Things is a desktop platform created to help communities/neighbourhood share tools, equipment, and other resources.

## Purpose:
- 🎯 Addresses the Theme: **Technology for Sustainable Futures** -- encourage sharing of existing resources
- ♻️ Reduced Consumption -- reusing items prevents unnecessary purchases
- 🤝 Community Driven -- connecting strangers through sharing
- 🔎 Resource Accessibility -- easily find things nearby

## Features:
- Register resources available for sharing.
- Support borrowing requests and booking management.
- Track resource availability and usage history.
- Generate statistics about resource utilisation.

- Java
- JavaFX
- FXML
- MVC
- CRUD
- CSS
- OOP
